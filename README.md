Sobre o projeto
Este projeto é meu portfólio pessoal. A proposta é reunir em um só lugar informações sobre minha formação, experiência, conhecimentos técnicos e aplicações que venho desenvolvendo para colocar em prática o que estudo.

O site foi construído com HTML, CSS e JavaScript, priorizando uma apresentação objetiva, identidade visual escura com detalhes em vermelho e adaptação para diferentes tamanhos de tela.
O que você encontra no portfólio
- Apresentação: introdução profissional e acesso ao meu currículo.
- Sobre: um pouco da minha trajetória e dos meus interesses na tecnologia.
- Competências: áreas e conhecimentos que venho desenvolvendo.
- Formação e experiência: minha formação acadêmica e experiência profissional.
- Ferramentas: tecnologias e ferramentas com as quais tenho contato.
- Projetos: aplicações e estudos práticos, com links para repositórios e demonstrações quando disponíveis.
- Contato: caminhos para conectar-se comigo pelo GitHub, LinkedIn ou e-mail.

Executar localmente
Como este é um site estático, não é necessário instalar dependências ou executar um processo de build.
1. Clone o repositório:
   git clone https://github.com/KaioMungo/NOME-DO-REPOSITORIO.git
2. Entre na pasta do projeto:
   cd NOME-DO-REPOSITORIO
3. Abra o arquivo index.html no navegador. Se utilizar o Visual Studio Code, também é possível executar o projeto com a extensão Live Server.
Substitua NOME-DO-REPOSITORIO pelo nome exato do repositório no GitHub.
